# Quest Of The Enigma Crystal

## Description
This project was part of a group project for the [Computerspilteknologier](https://kursuskatalog.au.dk/en/course/120504/Computerspilteknologier) course at Aarhus University. The project was developed by a team of four students, each contributing to different aspects of the game.
This game project is a barebones version of the envisioned project showcasing a little bit of each aspect of the game.

## My Contribution
Throughout development the team helped each other across the different sections of the project to ensure a cohesion and integration. My main contribution to this project has been in the development of the [combat arena](./Assets/Scripts/combatarena).
